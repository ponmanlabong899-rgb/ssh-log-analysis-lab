# SSH log analysis lab

Python scripts I wrote to find password-guessing attacks in SSH logs. I built and ran everything on an Android phone, using Kali Linux (NetHunter) in Termux. This is a beginner learning project.

## What the scripts do
They read an SSH log, count failed password logins per IP address, flag any IP above a threshold, and check whether a flagged IP later logged in successfully. The results are saved as a CSV file and a text summary.

## Files
- make_log.py: builds a practice SSH log (301 lines) with three attacker IPs and one planted root login
- analyse_log.py: analyses the practice log
- analyse_ssh.py: analyses a real OpenSSH log. Usage: python3 analyse_ssh.py LOGFILE THRESHOLD
- practice_failed_by_ip.csv and practice_summary.txt: results for the practice log
- real_failed_by_ip.csv and real_summary.txt: results for the Loghub sample (threshold 10)

## How to run
    mkdir -p ~/lab/logs ~/lab/reports
    python3 make_log.py
    python3 analyse_log.py
    python3 analyse_ssh.py ~/lab/logs/ssh_sample.log 10

## Results
Practice log: 193 failed logins, 88% from three IPs, and one successful root login from one of them.

Real sample (Loghub OpenSSH, 2,000 lines): 517 failed logins from 23 IPs. Six IPs made 91% of them (I chose a threshold of 10 because no IP had between 7 and 17 failures), and none of the six got in. The one successful login came from an IP with no failed attempts.

## Limitations
- The practice log is made up, so its results show the method and not a real attack.
- The real sample is only 2,000 lines of a much larger dataset.
- Only password logins are counted.
- The threshold is set by hand from the data.

## Data
The practice log is generated by make_log.py. The real sample is not included. Download OpenSSH_2k.log from https://github.com/logpai/loghub/tree/master/OpenSSH.
Source: Loghub, Zhu et al., ISSRE 2023. The datasets are free for research or academic use, and the paper should be cited.
